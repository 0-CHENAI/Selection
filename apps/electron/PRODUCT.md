# Product

## Register

product

## Users

Knowledge workers and developers who coordinate multiple AI-agent sessions, connect external services, and manage document-centric work from a desktop application. They need to keep several long-running tasks moving without dropping context or switching to configuration-heavy command-line workflows.

## Product Purpose

Selection provides an opinionated, agent-native desktop workspace for multitasking with powerful AI agents. It makes sessions, sources, skills, automations, permissions, and background work understandable and persistent, while allowing users to connect APIs and services with minimal setup. Success means users can confidently start, leave, resume, inspect, and share agent work without losing progress or wondering whether an operation really completed.

## Brand Personality

Fluid, confident, and pragmatic. The product should feel capable and carefully opinionated without adding ceremony, fluff, or configuration friction.

## Anti-references

Avoid CLI-first workflows, setup wizards that expose implementation details, decorative enterprise dashboards, ambiguous success feedback, and modal flows that trap users until long-running work completes.

## Design Principles

- Keep the user in flow while work continues independently.
- Make durable system state visible and trustworthy.
- Prefer direct actions and progressive disclosure over setup ceremony.
- Use one consistent interaction vocabulary across agents, sources, and automations.
- Pair powerful automation with clear permissions, recovery, and user control.

## Accessibility & Inclusion

Interactive controls must be keyboard operable, expose semantic names and states, and provide visible focus feedback. Status must never rely on color alone. Motion should communicate state changes, remain brief, and respect reduced-motion preferences. Errors and progress updates must be readable and recoverable.
