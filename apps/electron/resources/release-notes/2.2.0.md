# v2.2.0 — Selection

## Improvements

- **正式答案真实流式展示** — 正式答案边生成边出现在主卡片上，不再等整篇参数到齐，也取消完成后的揭示等待。未分类正文直接增长，不再先折进工作链再回放。([#350](https://github.com/0-CHENAI/Selection/issues/350)、[#404](https://github.com/0-CHENAI/Selection/issues/404))

- **成果文件与预览** — 最终回复底部按宽度展示成果文件，可展开收起，并提供打开方式和在文件管理器中显示。HTML、Markdown 内联预览限制高度，溢出时底部渐隐，完整内容在弹窗中阅读。Office、PDF、图片和文本使用专用图标。([#410](https://github.com/0-CHENAI/Selection/issues/410)、[#409](https://github.com/0-CHENAI/Selection/issues/409)、[#408](https://github.com/0-CHENAI/Selection/issues/408)、[#407](https://github.com/0-CHENAI/Selection/issues/407))

- **工作链与会话导航** — 思考和步骤共用一条标题过渡，折叠态不再附加错误计数。思考链路展示完整详情，左侧会话记录支持刻度定位和悬停预览。上下文用量收口到输入区圆环。用户消息在气泡下方复制。([#405](https://github.com/0-CHENAI/Selection/issues/405)、[#397](https://github.com/0-CHENAI/Selection/issues/397)、[#388](https://github.com/0-CHENAI/Selection/issues/388)、[#368](https://github.com/0-CHENAI/Selection/issues/368)、[#372](https://github.com/0-CHENAI/Selection/issues/372)、[#386](https://github.com/0-CHENAI/Selection/issues/386))

- **设置与高级开关** — 移除输入页、项目颜色高亮和设置页「更多 / 在新窗口中打开」。未配置数据源时使用标准设置卡片，连接图标改为供应商图标。新增高级设置：DAG 编排和 Swarm 子代理默认关闭，AnySearch API Key 只保存在本地且不回显。([#413](https://github.com/0-CHENAI/Selection/issues/413)、[#380](https://github.com/0-CHENAI/Selection/issues/380)、[#346](https://github.com/0-CHENAI/Selection/issues/346))

- **编辑浮窗** — 点击外部只失焦，不再直接关闭。缩放改为拖动右边、底边或右下角，左上角保持固定。([#384](https://github.com/0-CHENAI/Selection/issues/384)、[#385](https://github.com/0-CHENAI/Selection/issues/385)、[#382](https://github.com/0-CHENAI/Selection/issues/382))

- **自动化与入口精简** — 删除智能事件、全局待办和技能页「创建任务」入口。定时任务与事件触发的创建上下文互相隔离。([#371](https://github.com/0-CHENAI/Selection/issues/371)、[#357](https://github.com/0-CHENAI/Selection/issues/357)、[#347](https://github.com/0-CHENAI/Selection/issues/347)、[#362](https://github.com/0-CHENAI/Selection/issues/362))

- **表格、来源与写作** — 表格和对比默认使用内置表格。参考来源在流式过程中不再闪动，完成后不把卡片撑高。成稿和修订可以按需读取内置自然写作说明。应用图标换为 macOS 27 Liquid Glass 天鹅。

## Bug Fixes

- **兼容网关可以调用推理模型** — 系统提示改为 `system` 角色，ORDER 等网关不再因 `developer` 拒绝 MO 等开启思考的模型。([#415](https://github.com/0-CHENAI/Selection/issues/415))

- **交付与长任务不再卡死** — 同一轮写完 HTML 再提交答案时不再要求单独调用并反复失败。只有长时间完全没有输出才会停止，思考和正文会重置等待。服务器无负载时，客户端不再一直停在运行中。([#361](https://github.com/0-CHENAI/Selection/issues/361)、[#363](https://github.com/0-CHENAI/Selection/issues/363)、[#360](https://github.com/0-CHENAI/Selection/issues/360))

- **图片、Windows 顶栏与 MCP** — 本地图片、file 和 data 图片可以正常显示。Windows 窗口按钮不再挡住关闭入口和图片预览工具栏。MCP 不再因 Pi subprocess transport 不可用而失败，技能与 MCP 配置完成后浮窗不再突然消失。Mermaid 缩放需要手势解锁，避免挡住会话滚动。([#358](https://github.com/0-CHENAI/Selection/issues/358)、[#359](https://github.com/0-CHENAI/Selection/issues/359)、[#356](https://github.com/0-CHENAI/Selection/issues/356)、[#396](https://github.com/0-CHENAI/Selection/issues/396)、[#394](https://github.com/0-CHENAI/Selection/issues/394)、[#390](https://github.com/0-CHENAI/Selection/issues/390))

- **项目内新建会话使用项目目录** — 从项目新建会话时继承该项目的工作目录，而不是工作区默认目录。([#406](https://github.com/0-CHENAI/Selection/issues/406))
