# v2.0.0 — Selection

## Features

- **V3 编排支持真正的人机协同** — 无需编写 YAML 即可创建和编辑编排：AI 生成待审阅的提案，可应用到未保存的草稿，增删改节点与依赖后再显式保存，YAML 导入仍为可选入口。人工审批节点展示运行中的定义与上游输出，反馈在重启后保留，未审批前保持门控。创建本身不会启动运行。已有任务继续使用版本化编辑，`orchestrate` 仍保留预览／显式开启门槛。([#288](https://github.com/0-CHENAI/Selection/issues/288))

- **编排模板库** — 可将通过校验的 V3 定义保存为工作区可复用模板：卡片浏览、只读架构图、查看节点定义，并据此创建新的编排实例。保存或使用模板都不会启动运行，模板存放在 `tasks/` 之外。([#286](https://github.com/0-CHENAI/Selection/issues/286))

## Improvements

- **任务看板改为新建编排编辑器** — 列表／编排切换器保留，但第二视图现在直接打开既有的新建／编辑编排编辑器，不再是列、卡片、拖拽或看板筛选；列表为项目范围时，新建的编排会绑定到该项目。([#261](https://github.com/0-CHENAI/Selection/issues/261))

- **统一 V3 YAML 编排导入，并修复创建与保存边界** — 新建的持久化编排统一走 V3 YAML 导入；已有任务继续版本化编辑，不会自动升级到 V3。导入不会自动运行，默认按 conduct 处理，orchestrate 保留预览／显式开启门槛。补齐导入入口文案、无绑定目标时的明确拒绝、旧生成逻辑清理与导入错误本地化；V2 给出拒绝与改正重试，V3 导入兼容中文路径、重复 ID、解析错误与取消导航，并修复 V1 表单保存误触发 V3 升级确认的问题。([#284](https://github.com/0-CHENAI/Selection/issues/284))

- **列表与导入编排控件不再在视图间跳动** — 桌面端把搜索与切换器放在工作区选择器之后的同一个顶栏槽位。进入或离开 YAML 导入编辑器时只改变切换器选中项与主内容，项目上下文与返回导航保持完整；未保存的 YAML 或已有任务编辑会在任一控件离开编辑器前得到确认。([#283](https://github.com/0-CHENAI/Selection/issues/283))

- **会话区改为「搜索 + 列表／新建编排」** — 放大镜入口紧邻切换器左侧，仍打开原有的会话搜索框；紧凑宽度下搜索保留在列表标题栏，切换器隐藏。([#264](https://github.com/0-CHENAI/Selection/issues/264))

- **移除会话列表的筛选与分组菜单** — 标题栏的 ListFilter 控件不再提供项目包含／排除，也不再有未读或项目分组。列表始终按日期分组；已保存的排除或多项目筛选会在加载时清除，使其无法继续隐藏会话，侧栏的单个项目包含则保留。([#263](https://github.com/0-CHENAI/Selection/issues/263))

- **桌面顶栏精简** — 移除品牌菜单、创建任务图标与添加面板的加号；侧栏、返回／前进、工作区与浏览器徽标保留。创建任务仍在后台校验并通知，重新打开／停止入口位于来源、技能与自动化页面的标题栏；面板内的新建聊天仍用快捷键，紧凑模式保留移动端应用菜单。([#262](https://github.com/0-CHENAI/Selection/issues/262))

- **Windows 原生标题栏与 Selection 顶栏融合为一行** — 多余的独立标题栏条带消失，最小化、最大化、关闭通过 Windows overlay 保持在右侧，其余区域保持可拖拽，并保留侧栏、返回／前进与工作区控件。([#260](https://github.com/0-CHENAI/Selection/issues/260))

- **会话菜单移除「连接消息平台」入口** — 桌面会话菜单与紧凑模式抽屉中的该入口一并移除，同时清理不可达的 messaging hook、面板、预览、registry 条目与翻译键，并修复移除后首项出现空分隔线的问题。([#281](https://github.com/0-CHENAI/Selection/issues/281))

- **精简消息平台集成** — 彻底移除已下线的 Telegram、WhatsApp 集成及其设置界面、后台 worker 与打包依赖。已有安装只会丢弃这些集成过时的凭据与本地状态，Lark／飞书配置与绑定保持不动。([#280](https://github.com/0-CHENAI/Selection/issues/280))

- **全面统一 Selection 天鹅标识** — 就绪的空会话在输入框上方展示天鹅与 CATHALIE 字体的 Selection 字标，两处标识按下边缘对齐。同一套天鹅标识替换了原有的圆形标记，覆盖引导页、启动页、菜单、查看器、桌面资源以及 WebUI／PWA 图标；新会话字标会在发出首条消息后消失，并在紧凑、加载中、失败与只读状态下不出现。([#275](https://github.com/0-CHENAI/Selection/issues/275))

- **外观设置不再暴露工具图标映射** — 设置 → 外观隐藏了工具图标表格与编辑入口；聊天仍从 `~/.selection/tool-icons/` 解析 CLI 图标，并在启动时把首次运行时残留的 Selection／`craft-agent` S 标记替换为内置天鹅。([#307](https://github.com/0-CHENAI/Selection/issues/307))

- **统一 Skill 默认图标** — `SkillAvatar` 在没有自定义图标时的默认回退由 `Zap` 统一为 `Sparkles`，技能列表与详情页头部不再出现两套默认图标。([#277](https://github.com/0-CHENAI/Selection/issues/277))

- **中文界面日期显示本地化** — 简体中文与日文的会话日期分组改为 `M月D日`，搜索结果日期分组跟随当前界面语言，简体中文的紧凑相对时间改为「3天前」「3个月前」等无歧义写法。([#289](https://github.com/0-CHENAI/Selection/issues/289))

- **升级内置 OfficeCLI 至 v1.0.147** — 桌面运行时、官方 Schema／Guides／Skills 与六个平台资产已同步到上游稳定版；`import` 新增的 `--delimiter` 与 `--decimal` 参数已纳入命令分类审查，运行时自更新仍保持禁用。([#276](https://github.com/0-CHENAI/Selection/issues/276))

- **统一 macOS Dock 图标尺寸** — 为 Dock 与 ICNS 图标添加透明外边距，并把白色底板与天鹅整体缩至约 83%，改善与其他应用并排时明显偏大的问题。([#315](https://github.com/0-CHENAI/Selection/pull/315))

- **聊天标题居中与品牌标识尺寸** — 搜索入口移至会话列表标题栏右侧，顶部「列表／新建编排」居中；聊天标题按面板居中，空会话品牌标识调整为原尺寸的 75%。([#306](https://github.com/0-CHENAI/Selection/pull/306))

## Bug Fixes

- **开发者反馈必须逐次取得明确授权** — `send_developer_feedback` 从无条件允许改为逐条显式确认：令牌由 host 注入并与精确消息绑定，缺失、篡改或重复使用都会失败关闭；反馈记录不再保存 sessionId，系统提示禁止工具报错后主动上报，确认界面也不再显示会误导授权范围的「始终允许」。([#230](https://github.com/0-CHENAI/Selection/issues/230))

- **顶部栏返回／前进重新跟随真实的应用内历史** — 从会话或项目返回时不再被自动选中或 `replaceState` 同步立刻覆盖；按钮可用状态与 `pushState`／`popstate` 跟踪同一游标，返回后再发生新导航会丢弃旧的向前分支。([#259](https://github.com/0-CHENAI/Selection/issues/259))

- **对话框内的 Error 悬浮提示不再被预览窗遮挡** — 失败工具的 Error 徽标现在打开有边界、可滚动的提示；当徽标位于对话框（含子代理预览）内时，提示使用对话框之上的嵌套层级，而不是被压在后面；主会话提示保持默认层级。([#254](https://github.com/0-CHENAI/Selection/issues/254))

- **Swarm Markdown 交付不再被 `_content`／伪预览工具打断** — 兼容端点发出的 `write({ path, _content })` 会在 schema 校验前恢复为 `{ path, content }`，同时不放宽额外字段拒绝、不绕过 PreToolUse／路径权限。系统提示明确 `markdown-preview` 是围栏回复语法而非工具，这类伪工具调用改按 provider／model 计数，不再被重写成文本。([#255](https://github.com/0-CHENAI/Selection/issues/255))

- **空回复诊断与恢复提示** — 区分工具执行后缺少最终回复、上下文限制、流中断与代理进程退出，保留本轮具体错误并提供中英文说明；工具执行后不再提供可能重复操作的重放式重试。([#295](https://github.com/0-CHENAI/Selection/issues/295))

- **编排运行时在会话主界面显示实时进度并保持运行态** — 「创建并运行」仍进入编排会话，该会话现在在主区域列出各节点的实时状态，不再只剩定义确认与输入框的 Swarm 药丸；子节点仍在运行时，定义确认隐藏重新生成／复制／Markdown，输入框显示停止而非发送。([#274](https://github.com/0-CHENAI/Selection/pull/274))

- **编排超时诊断与失败恢复** — 区分模型服务超时、SSE 心跳、模型输出与上游流内错误，在错误详情中保留脱敏请求标识、阶段耗时与重试次数，避免错误串用和隐式重发；为瞬时连接错误提供默认退避，并修复等待重试时提前结束的问题。普通会话 DAG 可只重试失败节点，保留成功依赖与累计预算，并重新执行必要的审批与验收；新增脱敏 SSE 阶段日志以辅助定位上游连接问题。([#297](https://github.com/0-CHENAI/Selection/issues/297))

- **编排实例与运行历史** — 主会话保留已停止、失败及完成的运行记录，可切换历史运行并逐一查看并行实例与旧尝试；最近失败运行支持明确重试，停止后迟到创建的子会话不再继续执行。([#297](https://github.com/0-CHENAI/Selection/issues/297)、[#304](https://github.com/0-CHENAI/Selection/issues/304)、[#305](https://github.com/0-CHENAI/Selection/issues/305))

- **完整的技能安装链路** — 新增技能检查与安装工具，一次调用完成获取、静态校验、安装及加载确认；同名更新要求明确指令与内容指纹，失败时恢复旧版本，无需再发送「继续」补校验，Windows 下的技能安装事务与初始化失败锁也已兼容。([#310](https://github.com/0-CHENAI/Selection/issues/310))

- **消除 DAG 输出发布与连接池释放的竞态** — 节点完成时，先在节点终态与连接池释放对调度器可见之前持久化并发布 attempt／definition／instance output，避免下游 `map`／`for_each` 观察到「依赖已完成、输出尚不存在」的中间状态而把未解析表达式或空值当输入展开。连接池释放通知改为只唤醒等待槽位的兄弟 run，来源 run 在完成事务末尾沿既有路径自行调度，以避免同步重入。([#312](https://github.com/0-CHENAI/Selection/issues/312))
