# v2.1.1 — Selection

## Improvements

- **删除项目文件夹时同步删除其中的会话** — 删除项目后，其会话此前只是被解绑，仍会出现在普通对话和搜索结果中。现在通过 SessionManager 同步删除关联会话，清理磁盘记录与运行状态，并广播删除事件刷新对话列表。内存与磁盘中的会话以最新内存归属为准同时处理，其他项目与普通会话不受影响；会话清理失败时保留项目以便重试。删除确认提示已更新为说明会话将同步删除、配置的工作目录保留。([#343](https://github.com/0-CHENAI/Selection/issues/343))

- **项目文件夹新增省略号操作菜单** — 侧边栏「项目」下每一行新增与现有菜单样式一致的省略号按钮，支持重命名、在系统文件资源管理器中显示和删除。重命名拒绝空白名称，并防止中文输入法选词时误提交；菜单按钮与导航按钮的点击及键盘事件相互隔离，避免误切换项目，长名称截断显示。([#342](https://github.com/0-CHENAI/Selection/issues/342))

- **正式答案边生成边以真实流式展示** — 正式答案此前要等整篇 `submit_answer` 参数到齐后才出现，现在参数生成期间即显示临时 Markdown 预览，服务端接受后在同一张卡片替换为规范正文，并取消完成后约两秒的本地揭示等待。预览不持久化，取消、错误、拒绝与迟到事件都不会变成正式答案；OpenAI Completions／Anthropic 拦截器新增按异步请求隔离的预览通道，保留原有元数据剥离与单次 SDK 工具执行。([#350](https://github.com/0-CHENAI/Selection/issues/350))

- **技能页移除「创建任务」入口与弹窗** — 移除「所有技能」标题栏右上角的「创建任务」入口及其弹窗，使导入与新增技能按钮保持连续、清晰的布局。创建任务的后台能力仍保留在来源与自动化页面，技能导入与「+」新增技能不受影响。([#347](https://github.com/0-CHENAI/Selection/issues/347))

- **设置页移除三点菜单与「在新窗口中打开」** — 移除所有设置分类项共用的三点菜单按钮，以及「在新窗口中打开」菜单项与相关深链接处理逻辑；点击分类项后在当前窗口切换设置内容的行为保持不变。([#346](https://github.com/0-CHENAI/Selection/issues/346))
