## Features

- **Claude Opus 4.6 is back as a selectable model** — restored by popular demand (craft-agents-oss#1007). It appears again in the model pickers for direct Anthropic connections, Amazon Bedrock, and Pi-backed catalogs. Connections that previously had it force-migrated to Opus 4.8 get Opus 4.6 re-added automatically (one-shot — your default model is left untouched, and removing it again sticks). Opus 4.8 remains the default for new installs

## Bug Fixes

- Explore mode no longer goes silent when a tool call is blocked — since the v0.11.3 SDK uplift, the first blocked tool ended the turn before the agent could respond. The agent now sees the block reason again and can suggest switching modes or submit a plan instead of stopping without a word
