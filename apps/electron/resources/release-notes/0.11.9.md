# v0.11.9 — 生成内容超链接与 ORDER 设置

## 修复

### 生成内容里的本地文件链接

- Windows 盘符路径、`file://D:/…`、百分号编码、中文工作区相对路径均可点开
- 带空格的未加引号路径（如 `D:\巡察工作\my file.md`）不再被截断
- 误识别的 `http://SKILL.md` 会按本地文件打开
- 不再把工作区名拼成 `巡察工作\巡察工作\…`；搜不到时从工作区（及 ASCII 上级目录）回退查找

### 技能复制与芯片（此前版本一并带上）

- 中文工作区下 Skill / MCP 复制不再报 `Staging copy failed`
- `/` 选择技能后正确显示芯片，而不是 `[skill:巡察工作:…]`

## 欢迎页与 ORDER

- **Selection** 产品名使用内置 CATHALIE 字体（仅这几个字，不改动整站字体）
- ORDER 端点改为两个按钮：**Anthropic 兼容** / **OpenAI 兼容**，不暴露 URL
- 填入 API Key 后通过 `/v1/models` 拉取模型列表；点选后候选面板关闭
- 默认模型占位：例如 Opus，Laufry，Maylo...

## 升级说明

请安装 **0.11.9**，在「关于」中确认版本后，再验证生成内容中的文件链接能否打开。
