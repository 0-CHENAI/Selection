# v0.11.6 — 中文工作区 Skill 体验修复

## 修复

### Windows 中文路径 Skill / MCP 复制

- **Skill / Source 复制**：不再使用 `fs.cpSync` 在中文父目录下创建临时目录（会“假成功”导致 temp dir missing）
- 改为在系统临时目录（纯 ASCII 路径）中完成暂存，再手动逐文件复制到目标路径
- 兼容跨盘符（如 `C:\Temp` → `D:\selection\巡察工作\...`）与杀毒软件占用导致的 rename 失败

### 输入框技能芯片渲染

- 选择技能后不再显示原始文本 `[skill:巡察工作:inspection-workflow]`
- 支持 **中文工作区名** 的 mention 解析，正确渲染为技能芯片（如「巡查工作流」）

## 升级说明

请安装 **0.11.6** 后确认应用版本，再验证复制 Skill 与 `/` 选择技能芯片显示。
