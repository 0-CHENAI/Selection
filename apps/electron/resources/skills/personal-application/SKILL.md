# 请假、报销与其他申请表

用户要请假条、差旅报销、用印或其他申请表时用本技能。成品是 Word 表格。表是给申请人填写、给审批人留空的，不代表已经批准。不代签、不写「同意」、不填审批日期。

用户明确要求可勾选、可填写的域时，再读 OfficeCLI 的 `officecli load_skill word-form`，按它的域来做。普通申请表用表格即可，不要为了「像系统」硬做一堆域。

## 每种表至少有的栏

请假：申请人、部门、假别、起止时间、天数、交接人、事由、本人签字、日期。天数能由日期算出时写明含首尾与否，不在表里用一个说不清的公式假装精确；Word 里日期差不好维护时，天数由用户填写，表上注明「按单位规定计算」。

报销：申请人、部门、事由、行程或费用明细（日期、项目、金额）、合计、附件张数、本人签字。合计用表格能表达的加总；若明细超过十行或以后还要改数，改做 Excel，Word 只留封面说明。金额只写用户给的，没有就标待补充。

用印：用印事由、文件名称、份数、印章种类、经办人。不写「已盖章」。

审批栏固定在表的下半：意见、签字、日期，三格都空着。不要填样例里的审批人。

## 必填规则

用户没给的必填项，格子里写「待补充」，不留白到看不出还要填。选填项写「选填」。不要用灰色的示例姓名冒充已填写。

身份证件号、银行卡号，用户没要求出现在这张表上就不收集。报销收款账户只在用户提供时填写。

## 版式

- A4，页边距不窄于 1.8 厘米。标题黑体居中。
- 表格外框实线，表头浅底。标签列窄、填写列宽。行高够手写签字。
- 一页能放下的申请不要拆成两页。明细太长时明细另页，首页保留合计和签字。
- 不放单位公章图片。

## 自检

- 申请人、事由、时间或金额、签字栏都在。审批栏是空的。
- 样例的出差城市、金额、人名没有残留。
- 没有「审批已通过」。
- 必填空项都标了待补充。
- `validate` 已通过。用 `office_render` 看表格有没有撑出页边、签字栏有没有被切到下一页只剩一条线。

## 常见错误

- 把报销明细的样例数字留在合计里。
- 请假天数和起止日期对不上还不标明。
- 用印申请写成合同。用印只说明盖哪份文件，不重写文件正文。
- 替领导写「同意，请财务办理」。

## 文件交付

先 `officecli load_skill word`。需要填空域时再加载 word-form。不要用 Python 或 LibreOffice。样例只读。交付前走版式守卫。
