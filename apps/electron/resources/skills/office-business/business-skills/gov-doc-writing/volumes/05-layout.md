# 版式

版式依据 GB/T 9704-2012《党政机关公文格式》的公开要素整理，供排版核对。不替代标准全文。单位模板与这里不一致时，用单位模板，并在交付说明里写明差异。做不到的项目写「待核对」，不声称已经满足。

## 页面

- 用纸 A4，210 毫米 × 297 毫米。Word 中页面尺寸为宽 11906 缇、高 16838 缇。
- 页边距：上 37 毫米（2098 缇）、下 35 毫米（1984 缇）、左 28 毫米（1587 缇）、右 26 毫米（1474 缇）。版心约 156 毫米 × 225 毫米。允许约 1 毫米的印制误差；超出就改，不靠视觉上「差不多」。
- 正文一般每面 22 行、每行 28 字。做不到精确网格时，在交付说明里写实际行距，不声称已经满足该行数。
- 文字一般用黑色。红色只用于发文机关标志和版头分隔线。

## 字号

没有特殊说明时，格式要素用 3 号仿宋。下面这些位置改用指定字体，不整篇只用一种字。

| 位置 | 字体 | 字号 |
| --- | --- | --- |
| 发文机关标志 | 小标宋 | 红色，高度按版心比例居中，不小于标题 |
| 份号、密级、紧急程度 | 黑体 | 3 号 |
| 发文字号 | 仿宋 | 3 号 |
| 「签发人」三字 | 楷体 | 3 号 |
| 签发人姓名 | 仿宋 | 3 号 |
| 标题 | 小标宋 | 2 号 |
| 主送、正文 | 仿宋 | 3 号 |
| 第一层「一、」 | 黑体 | 3 号 |
| 第二层「（一）」 | 楷体 | 3 号 |
| 第三层「1.」和第四层「（1）」 | 仿宋 | 3 号 |
| 抄送、印发机关、印发日期 | 仿宋 | 4 号 |
| 页码 | 宋体，半角数字 | 4 号 |

2 号约为 22 磅，3 号约为 16 磅，4 号约为 14 磅。OfficeCLI 用磅值写到 run 上，并分别指定西文和中文字体，避免中文落到 Calibri。

## 版头

自上而下，有才排，没有不留空行冒充：

1. 份号。用户提供时用 6 位阿拉伯数字，顶格放在版心左上角。没提供就不设份号，不写「000000」。
2. 密级和保密期限。只在用户标明时出现，用 3 号黑体。不自行定密。
3. 紧急程度。只在用户标明时出现。紧急不改变文种。
4. 发文机关标志。机关全称或用户给出的规范化简称，加「文件」二字。红色小标宋，居中。上边缘至版心上边缘约 35 毫米。标志下空一行。没有全称就写「待补充：发文机关」，仍然保留红色和居中，不用示例案例的机关名。
5. 发文字号。机关代字、六角括号年份、序号、号，居中，3 号仿宋。年份标全，用〔〕，不用 [] 或 ()。序号不编虚位，不加「第」。缺代字或序号时整行「待补充：发文字号」。
6. 签发人。上行文才标。发文字号居左空一字，签发人居右。「签发人」三字用楷体，姓名用仿宋。没有姓名就不设这一栏，不写「签发人：×××」。
7. 红色分隔线。位于发文字号之下约 4 毫米，与版心等宽。做不出红线时在说明里标明，不用黑色下划线冒充已经验收。

## 主体

- 标题：机关、事由、文种齐全，2 号小标宋，居中。回行时按词断开，排列对称，不把一个词拆到下一行。
- 主送：标题下空一行，左侧顶格，3 号仿宋，最后一个机关后用全角冒号。多家主送按用户给的顺序，不自行按级别重排。
- 正文：3 号仿宋。层次只用「一、」「（一）」「1.」「（1）」这四级，一层一种序号，不跳级，不混用「第一章」除非用户指定法规体例。
- 附件说明在正文之后、署名之前，左空二字，写「附件：」和名称。多个附件用阿拉伯数字编号。没有附件就不设这一行。
- 署名位于成文日期之上，以日期为准居中。成文日期用阿拉伯数字，年份标全，月、日不编虚位，右空四字。没有日期就「待补充：成文日期」。
- 不加盖印章时，不留一个空白方框，也不用文字画章。用户声明有印章但没提供印模时，注明「印章待补」，不生成图片。
- 附注在成文日期下一行，左空二字，加圆括号，放联系人等用户提供的说明。
- 附件另面编排。「附件」二字及序号用 3 号黑体顶格，下空一行再排正文。

## 版记

版记放在末页，首尾分隔线与版心等宽。末条分隔线位于版心下边缘。

- 抄送机关：4 号仿宋，左空一字，「抄送：」后列用户给出的机关。没有就「待补充：抄送机关」。请示不抄送下级；材料若要求抄送下级，停下来指出，不照抄。
- 印发机关和印发日期：4 号仿宋。印发机关左空一字，日期右空一字，用阿拉伯数字。不把成文日期自动填成印发日期。
- 公开属性用户没说时写「待补充：公开属性」，不默认「公开发布」。

## 页码

页码用 4 号半角宋体阿拉伯数字，左右各一条一字线，放在版心下边缘之下。单页居右空一字，双页居左空一字。版记页是否编排页码按用户模板；说不清时保持模板原样，并写「页码待核对」。

## 三种特定版式

信函格式：机关标志用全称，不加「文件」二字。标志上边缘距上页边约 30 毫米。标志下是上粗下细的红色双线。距下页边约 20 毫米再有一条红色双线。发文字号顶格居版心右边缘。首页不显示页码。商洽函优先用这一式，除非用户要求普通文件式。

命令格式：标志由机关全称加「命令」或「令」组成，上边缘至版心上边缘约 20 毫米。令号在标志下居中。不用普通发文字号代替令号。

纪要格式：标志由会议名称加「纪要」组成。出席人员可放在正文之前。不因为叫纪要就加盖印章。

## 表格

公文中的横表不超过版心。表头重复，数字右对齐。表内字体不大于正文。跨页时表题和「续表」按用户模板；没有模板就在续表上方注明「续表」。
