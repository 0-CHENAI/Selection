# 安全与公开

下面六条是一票否决。命中任何一条，不把稿标成可外发。

| 编号 | 规则 |
| --- | --- |
| S1 | 用户标明涉密，或文面上已有密级，仍把内容写进对外稿、公告或聊天摘要 |
| S2 | 证件号、生物识别、精确家庭住址、银行账号没有脱敏，又不是文件必须的公开联系方式 |
| S3 | 把内部处理过程改头换面后写成公告、公报 |
| S4 | 编造文号、签发人、印章、会议决定或统计数字 |
| S5 | 几条单独看不敏感、合在一起能定位到具体个人，却没有用户授权 |
| S6 | 公开属性与文种冲突：涉密或内部材料被标成公开发布 |

## 脱敏

| 内容 | 写法 |
| --- | --- |
| 手机号 | 保留前三后四，中间打星，或改成「办公室电话待补充」 |
| 证件号 | 不出现连续号码，改成「身份已核对」 |
| 住址 | 写到区或街道，不写门牌，除非送达地址就是文件事项 |
| 银行账号 | 不写入正文 |
| 个人病情、宗教信仰 | 不写，除非用户确认文件必须引用并已授权 |

联系人如果是用户明确要印在版记上的办公电话，保留，并在说明里写「用户指定公开」。

## 公开度分级

动笔前选一档。用户没说时写「待补充：公开属性」，不默认公开。

| 分级 | 什么时候用 |
| --- | --- |
| 公开 | 公告、公报，以及用户明确说可以公开的通知 |
| 依申请公开 | 用户说对外提供但不是主动发布 |
| 内部 | 本机关或本系统传阅，不发到社会 |
| 涉密暂不公开 | 有密级或用户说涉密。本技能只保留提示，不生成密件正文 |

请示不抄送下级。内部材料不改成公报。
