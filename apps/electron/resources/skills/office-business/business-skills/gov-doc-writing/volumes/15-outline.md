# 提纲句式、起承转合和语气

公文提纲有固定的组织办法：一句定调，几个并列分项展开，必要时一句收束。写不出「公文味」，多半不是词不够，而是并列项不同构、分项里没有业务内容。这一册给出组织办法、动词选用和语气，不提供可以直接套用的口号。

## 一段的骨架

```
定调句（这一部分讲什么、要达到什么）
  分项一（动词 + 具体业务 + 效果）
  分项二（同样的结构）
  分项三（同样的结构）
收束句（可选：责任、时限或下一步）
```

分项有几个就写几个。材料里只有两件事，就写两项，不为了凑「三」「四」硬加。

## 定调句的六种写法

下面用「动词」「业务」「目标」三个槽位说明。槽位内容必须来自用户材料。

| 写法 | 结构 | 适合 |
| --- | --- | --- |
| 直陈 | 以「动词 + 业务」推动「目标」 | 总结成绩、汇报做法 |
| 抓手 | 以某项具体工作为抓手，推进「目标」 | 部署工作 |
| 聚焦 | 聚焦「业务」中的几个重点，保障「目标」 | 突出重点、攻难点 |
| 落实 | 抓实「业务」，确保「目标」按期完成 | 部署、督办 |
| 带动 | 用「业务」带动「另一项业务」 | 两项工作有因果关系时 |
| 践行 | 把上级要求落到「业务」，提升「质量或效率」 | 贯彻落实类材料 |

选法：汇报成绩用直陈或践行；布置工作用抓手或落实；讲重点和难点用聚焦或带动。全文的一级标题不要六种轮流用，选一两种保持一致。

## 分项的三种长度

| 长度 | 结构 | 字数 | 适合 |
| --- | --- | --- | --- |
| 短 | 动词 + 业务名词 | 8–12 字 | 简报、信息、表格里的事项栏 |
| 中 | 动词 + 业务名词，+ 效果 | 14–20 字 | 一般总结、讲话稿 |
| 长 | 「一是」+ 动词 + 业务名词，+ 效果句 | 18–26 字 | 正式报告、汇报材料 |

同一组并列项选同一种长度，句法一致，字数相差不超过四个字。

## 动词怎么选

按这件事在做什么来选，不按好听选：

| 在做什么 | 可用动词 |
| --- | --- |
| 往前推 | 推进、推动、加快、促进、深化 |
| 打基础、补制度 | 健全、完善、加强、夯实 |
| 改方法、提质量 | 优化、改进、提升、创新 |
| 抓重点 | 聚焦、突出、围绕、紧盯 |
| 把责任落下去 | 落实、压实、抓实、细化 |
| 给条件、兜底 | 保障、支撑、服务 |

规则：

1. 每个分项都要有具体的业务词。「加强管理」不合格；「加强施工现场扬尘管理」合格。
2. 同一组并列项的效果补语不重复用同一个词。
3. 动词表外的新造词、网络用语、口号式缩略语不用。用户材料里原有的规范提法照录，见 [17-sensitive-wording.md](17-sensitive-wording.md)。
4. 效果补语要能在正文里找到支撑。正文没有数据或事实支撑的「成效显著」「全面提升」删掉，或改成具体结果。

## 起、承、转、合

开头、过渡和结尾各有作用，先确定作用，再写句子。

### 开头：交代为什么写

| 场景 | 写什么 |
| --- | --- |
| 依据上级文件 | 依据的文件标题和文号（用户给的），加一句目的 |
| 落实会议 | 哪次会议、什么要求，加本文要做的事 |
| 针对问题 | 一句说明问题和影响，不夸大 |
| 例行工作 | 直接写「为做好某项工作，现将有关事项通知如下」 |
| 讲话开场 | 会议名称、目的，必要时一句感谢，不铺陈 |

开头不超过两句。不写和主旨无关的形势铺陈。

### 过渡：交代前后关系

| 关系 | 写法 |
| --- | --- |
| 由总到分 | 「具体做好以下几项工作」 |
| 由成绩到问题 | 「在肯定成绩的同时，也要看到以下不足」 |
| 由问题到措施 | 「针对上述问题，下一步重点做好以下工作」 |
| 由现状到目标 | 「到某年某月，实现以下目标」，目标见 [16-indicators.md](16-indicators.md) |
| 递进 | 「在此基础上」「同时」 |

### 结尾：交代要对方做什么

结尾按文种和方向选，见 [04-wording.md](04-wording.md)。讲话稿和总结的结尾落到下一步要做的事，不以口号收尾。

## 按单位性质调语气

| 单位性质 | 语气 | 注意 |
| --- | --- | --- |
| 党委机关 | 庄重、严谨 | 依据和程序写在前；提法照录，不自拟 |
| 政府及部门 | 务实、清楚 | 事项、责任单位、时限放在显眼处 |
| 国有企业 | 经营语言和党建语言并用 | 经营指标写口径；重大事项写明前置研究程序 |
| 事业单位 | 服务导向 | 对上用汇报口径，对服务对象用告知口径，不混用 |
| 基层组织 | 通俗、具体 | 群众能看懂；公示写明议事和公开的过程与时间 |

## 自查

- 并列项结构一致吗？数量和材料里的事项数一致吗？
- 每个分项有没有具体业务词？
- 有没有正文撑不住的效果词？
- 开头是不是两句以内、说清了依据或目的？
- 结尾是否和文种、方向匹配？
