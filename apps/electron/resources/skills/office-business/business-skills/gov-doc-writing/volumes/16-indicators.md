# 目标和指标怎么写

方案、计划、通知里的任务，以及总结和述职里的成绩，都要能被核对。这一册说明好指标的标准、各领域常用的指标维度和写法。指标的数值只来自用户材料或用户点名的公开资料；没有就写「待补充」，不估数。

## 好指标的四条

| 条件 | 说明 | 不合格的写法 |
| --- | --- | --- |
| 具体 | 说清对象和范围 | 「进一步提升服务水平」 |
| 可量 | 有数值、比例、数量或明确的完成状态 | 「明显改善」 |
| 有时限 | 写到年、月，必要时写到日 | 「尽快」「近期」 |
| 有责任 | 有牵头单位，必要时有配合单位 | 「各有关单位」且没有牵头 |

四条缺一条，就补，或写成「待补充：牵头单位」「待补充：完成时间」。

## 一条指标的写法

「到某年某月，由某牵头单位负责，把某对象的某指标从基数提高或降低到目标值。」

- 有基数就写基数，没有基数时不写「提高百分之多少」，改写目标值或完成状态。
- 写清统计口径：按自然年还是滚动十二个月，按户还是按人，含不含某类对象。
- 增速和总量不混成一句；同一指标在全文用同一个口径和单位。

## 各领域常用维度

下面只列维度，具体指标名和数值以用户材料为准。

| 领域 | 常用维度 |
| --- | --- |
| 经济和产业 | 产值或营收、增速、投资额、重点企业数量、新增市场主体 |
| 项目建设 | 开工数、完工数、投资完成率、节点按期率、竣工验收 |
| 营商环境 | 办理时限、一次办结率、网办率、企业诉求办结率、满意度 |
| 民生保障 | 就业人数、覆盖人数、发放金额、办结时长、服务点数量 |
| 生态环境 | 空气或水质达标率、排放强度、整改完成数、治理面积 |
| 乡村和农业 | 种植或养殖规模、集体收入、基础设施完成数、培训人次 |
| 安全生产 | 隐患排查数、整改完成率、事故起数和伤亡人数、演练次数 |
| 社会治理 | 矛盾纠纷化解率、信访办结率、网格覆盖、案件下降比例 |
| 党建和队伍 | 组织生活完成率、培训人次、发展党员数、问题整改完成率 |
| 国有企业经营 | 营收、利润总额、净利润、资产负债率、经营现金流、全员劳动生产率、研发投入强度 |
| 内部管理 | 制度修订数、流程时长、预算执行率、审计问题整改率 |

## 不同文种里的指标

| 文种或材料 | 怎么用 |
| --- | --- |
| 方案、计划、通知 | 写目标值、牵头单位和时限；分阶段的写每个节点 |
| 总结、述职、报告 | 写完成值，与年初目标或上年同期比较；比较口径写清 |
| 简报 | 写一两个最关键的数字，不罗列 |
| 请示 | 只写与请示事项直接相关的数字，如金额、数量、依据 |

## 国有企业的额外要求

- 经营数字注明是否经审计，未经审计的写「快报数」或「未经审计」。
- 同时出现「利润总额」和「净利润」时，不互相替代。
- 重大经营事项写明是否已按程序前置研究；材料没写的，标「待补充：研究程序」。

## 自查

- 每条任务都有可核对的完成标准吗？
- 牵头单位和时限有没有缺？缺的是否已标待补充？
- 全文同一指标的口径和单位是否一致？
- 有没有不是用户给的数字？
