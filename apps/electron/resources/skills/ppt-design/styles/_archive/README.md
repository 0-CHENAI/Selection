# 样例扩展归档

目录名是 `styles/_archive`（ASCII，避免安装包和 Windows 路径检查拒绝非 ASCII 文件名）。这些文件仍在仓库里，供对照和旧会话解析，但不会打进安装包。

移入这里的是选择器里不再展示的示例成稿：deck 源、逐页预览 WebP、整页 PDF，以及只有这些成稿引用的图片。`deck.json` 里的文字、版式和 `src` 路径没有改写。图片字节在 `assets/`，原来的 `styles/examples/_assets/` 路径记在 `asset-map.tsv`。安装包不包含本目录；开发仓库里文件还在，导出归档成稿前如需图片，按对照表把文件放回原路径。

选择器仍接受这些 id，避免旧会话直接报错。安装包里找不到对应文件时，会说明样例未随安装包提供。
