# G4：真实逐页视觉审查

**必做，不是 opt-in。** 上游视觉审查思想在 Selection 中改为实际 PPTX 的每页截图审查，不使用上游 Python、SVG 预览服务器或可选阶段。唯一门序见 [工作流](workflow.md) 和 [应用覆盖规则](../../officecli/ppt-selection-override.md)。

## 获取真正的画面

先通过实际 outline 得到准确页数；对每一已知页执行，所有 OfficeCLI 调用设置 `OFFICECLI_SKIP_UPDATE=1`：

```text
officecli view "<absolute-deck.pptx>" screenshot --page 1 -o "<dataFolderPath>/pass-1-slide-01.png"
```

对实际页 2…N 分别调用，输出均为绝对 scratch 路径。无需 shell 循环、jq、Python 或探测不存在的第 N+1 页。截图命令成功不等于看过截图：必须用可用的图片/视觉工具打开**每一页**，看真实文字与构图。总览可辅助看节奏，不能取代单页检查；解析 HTML、读取 DOM 或图形坐标不能替代视觉证据。

若内置截图不可用，可用环境已有的真实演示渲染器或实际渲染预览并截图。浏览器必须真正呈现页面再捕获画面，不能读取 HTML 源码后写 PASS。没有可用渲染/视觉路径时记录 **G4 blocked / not visually verified**，不可把静态检查改名为视觉检查。

## 逐页检查视角

| 维度 | 必须实际看见 |
|---|---|
| 主张与层级 | 页面主张清晰，只有一个主要焦点，正文支持标题；不是所有对象同等突出 |
| 字体与换行 | 无缺字/豆腐块，中文标点合理，不拆词/单位，不出现标题孤字或正文短尾行；字号可读且未偷偷缩小 |
| 适配与几何 | 无剪裁、遮挡、溢出、意外越界；同列对齐、基线、内边距、段间距一致；无透明遮罩假隐藏 |
| 关系表达 | 比较项可比，流程/时间方向明确，连接线端点正确，matrix 四格含义对应轴，不把有序信息画成无序卡片 |
| 图表与证据 | 数值、系列、分类、单位、期间、轴与基线诚实；标签完整不拥挤，引用与来源可读，insight 有证据支持 |
| 风格与节奏 | 符合锁定的风格、字体、配方；相邻不重复布局，3–4 页有内容依据的冲击/留白，不为节奏编造内容 |
| 资产与尾部 | 图像存在且未错误拉伸，关键主体未误裁；来源、页码和页脚不碰正文，无模板提示/调试文本 |

整体风格问题应回到计划/锁修正，不把系统性问题做成逐页补丁。图表 schema 验证、文字正确读回、截图视觉清楚是三类不同证据。

## 审查记录与修复

在 scratch 的审查记录中保存实际候选路径、审查次数、每页截图路径及 `页码 | 通过/缺陷/阻塞 | 观察 | 修复决定`。没有看到的页不能写通过。全通过可以第一轮结束，不人为找错。

1. **pass 1**：首次整套逐页检查。
2. 若有缺陷：按发现更新受影响计划/锁/规格，修复保存新候选，重复受影响 G1–G3，再对整套每页渲染检查，计 **pass 2**。
3. 仍需修复时只允许再做一次，随后整套检查计 **pass 3**。

计数属于整个用户任务，不属于文件、指南或审查者。换布局、拆页、重选候选、会话中断、pitch/Morph、换渲染器、独立 reviewer 均不产生额外三次。多人检查同一保存状态可作为同一 pass 的分工，不能另加“独立终审”。不要复制上游“修到干净”无限循环。

任何审查后的文档修改都使旧状态的视觉结论不足，必须由剩余一次检查覆盖。第三次仍有问题时停止修复，记录具体页码、已尝试修复和阻塞；不能做第四次，不能交付未审查修复并宣称已就绪。渲染失败或空白页本身是阻塞，不从待审页集合中删除。

## 可选 Morph / 3D

只有用户要求时增加静态画面的对象泄漏、遮挡、错误名称配对、ghost 生命周期检查，融入同一 G2–G4；不引入另一套配色/网格或循环。静态截图不证明播放时的 Morph 插值、3D 运动或目标查看器兼容。未在目标 PowerPoint/Keynote/WPS 播放器实际观察的行为明确列为未验证，不把“原生对象存在”写成“动画已验证”。
