# 版式

每套风格的 `layout` 写在它自己的 `deck.json` 里，形如 `01-cover`、`02-content`。这些 id 只用来区分相邻页，不是各套共用的版式名。具体坐标、页眉和页脚以锁定风格的参考页为准，不要套用另一套的网格。

结构版式在 [layouts/catalog.json](../layouts/catalog.json)。七套来自 ppt-master 的 SVG 页面，颜色是 token，默认主题是中性石板色。画布分别是 16:9、4:3、1:1、9:16 和 3:4。选用某一套时，deck 的 `canvas` 用该套的尺寸，不要把竖版页面硬塞进 960×540。图片位是虚线框，渐变已铺平。

相邻页的 `layout` 不能相同。一页只有一个主张。

参考页覆盖这些论证关系。选页时按关系找最接近的一页，再替换文字和数据：

| 论证关系 | 页面在论证里的作用 |
|---|---|
| 封面 | 一个主张。封面构图只属于这一套 |
| 结论先行 | 判断先出现，证据是少量大数字或短句 |
| 序列 | 一条序列，旁边写波峰、回升或阶段的读法 |
| 分叉 | 一个判断连到几条互相独立的证据或假设 |
| 矩阵 | 两个维度，只突出应该先做的那一格 |
| 对照 | 两个对象的同一组指标，或改前改后 |
| 流程 | 顺序、交接或反馈。连线必须对得上句子里的那一段 |
| 清单 | 指标、责任、风险或行动。偏离的行和保持的行要能分开 |
| 收束 | 一个问题，一项或两项行动 |

图表类别使用用户材料里的原词，单位写在标题、轴旁或来源里。内容页沿用该风格参考页的页眉、页脚线和页码。来源写这页数字从哪来；示例页的虚构句不能留在正式稿里。
