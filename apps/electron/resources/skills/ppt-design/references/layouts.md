# 论证版式：先关系，再套参考几何

[layouts/catalog.json](../layouts/catalog.json) 只说明选型。可执行坐标在各风格 `pages/*.json`。同一 layout 在 `swiss-signal` 与 `navy-brief` 里结构不同，不能假设共用槽位。

| layout | 信息关系 |
|---|---|
| `cover` | 主题、范围、一个识别性构图。每套封面必须独特，不能只换色。 |
| `conclusion` | 一页一个结论 + 少量可核对证据。 |
| `evidence-tree` | 假设拆成可独立验证的分支。 |
| `matrix` | 两条维度的 2×2，一格是建议行动。 |
| `waterfall` | 加减项与净结果必须能对上。 |
| `trend-callouts` | 有序趋势 + 对异常点的标注和解读。 |
| `scorecard` | 实际 / 目标 / 行动；例外行必须有动作。 |
| `gantt` | 工作流 × 时间，并标出决策门槛。 |
| `architecture` | 边界、交接、依赖，而不是图标墙。 |
| `case-compare` | 同一口径的前后或 AB 对照。 |
| `funnel` | 同一群体的阶段转化。 |
| `closing` | 一项具体下一步，不再重复分析。 |

相邻页禁止重复 layout。没有数据就不要硬套瀑布或漏斗。示例参考页里的数字都是虚构的，必须换成用户证据或标明示例。
