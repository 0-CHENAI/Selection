# 排版

画布是 **960×540 pt**。字号是磅，允许 **6–160**。文本框的 `valign` 用 `top`，`margin` 由引擎写成 0。单行高度按字号计；多行高度是 `size + (行数 - 1) × size × leading`。`leading` 不写时，字号 ≥ 40 为 1.05，≥ 24 为 1.12，其余 1.28。

## 字体

元素写 `$cjk` 或 `$latin`。引擎按 `--platform mac|win|linux` 换成主题字体。需要衬线和黑体并存时，在该元素上写 `font.face`：`latin` 是西文字体名，`cjk` 分 `mac`、`win`、`linux`。导出时西文和中文写成两条字体槽，不嵌入字体文件。含中日韩字符时必须用 `$cjk`，否则预检报 `font`。

这五套参考页的常见配对是：西文标题 Georgia、正文 Arial；中文 macOS 标题 Songti SC、正文 PingFang SC；Windows 标题 SimSun、正文 Microsoft YaHei；Linux 标题 Noto Serif CJK SC、正文 Noto Sans CJK SC。以该套 `design.md` 为准。

## 容量

每个文本都要有 `textCapacity.maxChars` 和 `textCapacity.maxLines`。预检按字宽折行：

- 中文和全角标点按 1 em。
- 空格约 0.30 em，数字约 0.56–0.58 em，大写约 0.68–0.72 em，小写约 0.51–0.56 em，`%` 约 0.9 em。粗体取区间里较大的那个。
- 汉字按文本框宽度折行。西文折行和宽度检查留 `fitSlack`：`max(6pt, 字号 × 0.5)`，用来盖住边距误差，盖不住再多一个汉字。
- 行首不放 `，。、；：！？）》」』】` 和 `, . ! ? ; : ) ] } %`。行尾不放 `（《「『【` 和 `([{"'`。
- 上一行已经有内容时，最后一行不能只剩一个字。
- 换行写成真实换行。字符串里的反斜杠加 n、r、t 会报 `literal_newline`。

`maxChars` 至少要盖住实有字符数。行数超出 `maxLines`、总高度超出文本框，或最宽的一行超出文本框加 `fitSlack`，都是 `over_capacity`。

## 字号下限

以锁定风格的 `design.md` 为准，包括参考页里已经使用的小图示标签。不要把这些标签统一放大到 16 pt。正文仍然不要为了塞进框里而缩到该风格正文下限以下；换行、加高文本框、换版式或拆页。

## 对比度

`$ink` 或省略颜色时，正文至少 4.5，大字（24 pt，或粗体 ≥ 18 pt）至少 3.0。写明其他颜色时，下限是 3.0，用来放行参考页里的次级灰和色块上的浅字。白字直接放在纸色上仍然失败。带透明度的填色会先和底下的颜色合成再测。
