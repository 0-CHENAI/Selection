# 个人与家庭预算

用户要家庭预算、个人预算、记账或月度收支时用本技能。成品是 Excel。这是记账和对照工具，不是理财建议，不推荐基金、保险或借贷产品，不预测收益。

## 表怎么分

默认两张表：

1. 「收支」：一行一个科目。列至少有科目、月预算、本期实际、偏差、偏差率。
2. 「汇总」：收入合计、支出合计、结余，以及按月的实际数。图放在这张表，数据引用「收支」，不另抄一份数。

收入和支出分成两段，不要混在一个没有标记的列表里。结余 = 收入合计 − 支出合计，用公式。

偏差 = 实际 − 预算。收入超了是正，支出超了也是正；在列标题写清「实际减预算」，避免把超支写成节省。偏差率 = 偏差 / 预算；预算为 0 时显示「待补充」，不要出现除零错误。

## 必填与可缺

- 期间：哪一年、从几月记到几月。用户只说「这个月」就只做该月，不铺 12 列空表充数。
- 科目由用户的生活来，例如工资、房租、餐饮、交通。样例科目可以当分类参考，金额必须换成用户的。用户没给的科目不编一个数，单元格标「待补充」。
- 预算和实际分开。只有预算、还没有实际时，实际列留空，不要把预算抄进实际。
- 结余为负时如实显示，不改成 0，也不写「建议削减某类开支」除非用户要求分析。分析也只描述表内差额，不给投资建议。

## 版式

- 标题写明「家庭」或「个人」以及年份。
- 输入格浅蓝，公式白底。收入段和支出段用不同的浅底色区分，但不要超过两种浅色。
- 金额右对齐、千分位、两位小数。列宽足够，不能出现 `###`。
- 汇总图用柱形或条形，比较预算与实际，或各月结余。图例写中文。饼图只在用户要看支出占比、且类别不超过六项时使用。
- 打印：汇总表横向、宽度一页。

## 自检

- 改一笔收入或一笔支出，结余和偏差同时变化。
- `xlsx_recalculate` 之后读回结余，与收入减支出一致。缓存还是旧数时不能交付。
- 样例里的工资、房租数字没有留在新表。
- 没有理财产品推荐，没有「预计年化」。
- 有图或要打印时用 `office_render` 看汇总表。只改一个实际数、图和打印设置没动，说明里写「未重新截图」。

## 常见错误

- 把全年预算除以 12 填进每个月，用户其实只给了全年一个数。问清再拆，否则只做全年一行。
- 报销退回记成收入，又在支出里留着全额，结余被抬高。退回冲减原支出，或单独列「退回」，两处不要同时记正。
- 图表的数据写死，改了表图不变。
- 用样例的「餐饮超支」结论套到用户身上。

## 文件交付

先 `officecli load_skill excel`。不要用 Python 或 LibreOffice。样例只读。交付前重算，并按 checks 核对结余和至少一处偏差率。
