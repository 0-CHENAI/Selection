# PRO 自动任务图

Mode: Operate. Local extension of Selection's existing desktop UI; code-led.

用户通过会话表达任务，PRO 自动组织执行。项目继续管理资料、会话与成果。手动编排不再暴露在产品导航中。

用户确认：点击聊天右上角图标后打开，不常驻聊天。任务观察窗保护阅读与检查的专注；窗外点击、Esc 和关闭图标均关闭，焦点返回入口。

继承现有字体、前景/表面/边界变量与 PRO 金色。借鉴 Beautiful UI Flowchart 的点阵画布、节点类型与名称层级、简洁连接；不复制其固定演示逻辑或全局主题。用户最新确认弃用 React Flow，使用原生 HTML 节点与 SVG 连线，复用 dagre 的依赖排布。

第一屏仅呈现最新任务依赖图和节点执行状态。按用户最新要求删除历史回放入口、时间轴与回放控件；删除全局多视图、全局执行记录、预检、计划变更和研究记录面板。节点只读，允许平移、缩放、适配与选择；选中显示详情与子代理会话。禁止编辑、保存或执行操作。

验收覆盖亮/暗主题、窄窗口、运行状态更新、修订一致性、加载/空/错误状态、关闭与键盘焦点；四节点并行到汇合案例完成联合证据。旧 board 深链接回到会话，项目数据与 PRO 自动执行后端保持可用。

最新布局约束：观察窗接近可用窗口大小，顶部仅保留任务标题、实时运行状态与关闭按钮，标题栏高 52px。删除重复图标、可见说明、节点数量和点击节点提示；说明仅供屏幕阅读器读取。正文直接显示画布，详情栏与画布顶部对齐直到窗口底部。节点卡片 288×128，收紧冗余卡片高度，以细边界区分中性表面；宽窗口默认左至右，窄窗口默认上至下，显式设定方向仍优先。画布按实际尺寸自动适配，底部一组缩放比例与适配按钮，保留拖拽平移、触控板平移/缩放、键盘和多节点概览。右侧按观察窗内容宽度的 32% 自适应，最小 400px、最大 560px，三页签「职责 / 成果 / 运行记录」，默认职责。职责直接显示完整任务要求、友好名称的依赖、预期交付；各页签内容直接完整显示，不设展开/收起；长内容在详情栏内滚动。成果只读取当前运行和执行尝试的真实输出，校验成果区分校验结论与证据摘要。执行记录依次展示执行概况、节点信息、完整指令与可选控制字段；任务标题、分区标题、字段标签和正文通过字号、字重、间距及细分隔线区分。详情顶部左侧用「返回任务图」加左箭头收起，窗口右上角仅保留关闭整个观察窗的 ×，避免相近的两个关闭图标混淆。窄窗口详情覆盖画布，宽度不超过 560px 或可用宽度，可返回任务图；状态更新保留所选页签、节点位置和平移缩放视角。

本次动效与 Windows 修正：运行中的任务使用轻微铜金/香槟金表面色，类型图标与文字紧凑排列，语义状态保持图标和文字。依赖连线使用 6px 线段与 6px 间隔的虚线，沿上游到下游方向每 2.4 秒匀速移动一个周期，末端保留清晰箭头；取代旧的小光点动效。已完成依赖保持绿色，通往正在执行节点的可用依赖保持 PRO 金色，其他依赖保持中性色；虚线移动仅指示方向，任务是否正在运行仍由节点状态表达。页面隐藏或画布被窄窗口详情遮挡时暂停，减少动态效果时保留静态虚线和箭头。选中节点卡片的金色实线外框替换为 PRO 金色虚线，顺时针缓慢流动，60 秒走完一周；页面隐藏或画布被窄窗口详情遮挡时暂停，减少动态效果时保持静态虚线。节点悬停与选择不移动连线锚点，保留原有圆角、表面和状态色。Windows 桌面观察窗完整位于原生标题栏下方，避让高度取既有 48px 顶栏和原生 titlebar-area 的较大值；关闭按钮在标题行内，36px 点击区域，亮暗主题和窄窗均可见。

## Direction contract

跨平台标题栏补充：macOS 与 Windows 桌面的观察窗垂直居中，上下留白等宽，均采用顶栏高度与 titlebar-area 的较大值，顶部完整避开原生窗口按钮。Web UI 上下留白为 20px，窄窗口为 16px。全窗遮罩覆盖应用顶部栏，与其他背景统一模糊；原生窗口控制按钮由系统绘制，保留清晰显示。正式任务图和 X6 预览共用此布局。保留窗外点击、Esc、关闭按钮及入口焦点恢复，关闭后不自动弹出入口说明。

THESIS: 用户首先读到真实的并行任务、依赖与状态，再检查某个任务的职责和已记录成果。

OWN-WORLD: 继承 Selection 的系统字体、亮暗中性色表面与 PRO 金色；完成/失败用语义色，类型与状态用小图标和文字，不引入新的品牌世界。桌面用户在日间和夜间持续读资料，跟随其所选主题。

STORY: 点击聊天入口打开最新任务图；选中节点后保留「职责 / 成果 / 运行记录」三个页签，分别理解任务要求、检查输出、查阅执行详情或子代理会话。任务图始终跟随当前运行，状态更新保留平移缩放、所选节点和页签；成果只读取对应运行与执行尝试的输出。移除历史回放及相关界面状态，保留当前运行的修订一致性校验。关闭后回到聊天。

节点详情切换采用用户指定 Bencho Icon Bar 的两阶段拉伸/收拢指示背景，外圆角沿用任务图工具栏/详情面板的 12px，内选中块沿用菜单的 8px，保留 Radix 页签的方向键、选中状态和内容关联。按钮条铺满详情内容宽度，三个功能等宽；选中按钮内显示功能名称，其余图标可悬停查看说明。名称在 240ms 内展开淡入、160ms 内收起淡出，图标随内容宽度平滑移动，快速连续切换保留退场动画。动画裁切不使用省略号，避免展开和收起时闪烁。窗口缩放后指示背景重新对齐。使用现有亮暗表面与 PRO 金色，不引入额外依赖；减少动态效果时直接切换。

FIRST VIEWPORT: 避让原生窗口控制按钮的观察窗，单行标题与运行状态，余下高度归画布；288×128 节点按依赖居中，宽窗横向阅读、窄窗纵向阅读，详情栏 400–560px 自适应，默认职责。窄窗口详情覆盖画布，可关闭恢复图。

FORM: 继承现有任务图的 canvas + inspector 结构，按用户明确布局要求做局部扩展。无候选方向排序和随机 seed；new-work.md §3 明确要求 local extension / precisely specified narrow request 不运行 concept-seed。无 catalog QUALITY BAR 卡，质量参照为用户反馈截图、已有 Selection 视觉体系、BeautifulUI Flowchart 的实际参考截图以及 craft-floor。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

适用范围说明：本轮为 ordinary extension，按 new-work.md §3 / §5 / §7 保留 incumbent 设计系统，不创建或覆盖 DESIGN.md；无产品随附 raster 资产，review 截图只作为开发验收证据。
