## 当前边界与人工验收

- macOS 原生 Shell 约束已实际验证；Linux 仅在 bwrap 及内核权限可用时启用。Windows 首版支持结构化文件工具的候选执行，缺少原生约束时阻止任意 Shell 与项目脚本，不提供共享写入回退。
- 项目语义验证目前发现已有 JavaScript 包的 typecheck/lint/test。不存在适用检查、依赖不可用或检查配置被修改时保留候选并明确暂停，不声称代码正确。
- 非 Git 原有文件须声明输入；首版不自动复制整个工作区、合并二进制内容或应用发现的文件删除。
- 以上是框架和核心链路验证，不是所有平台、真实模型与故障组合的发布验收。按 [人工测试清单](task-reliability-manual-testing.md) 集中验证后再决定推送/PR。
