# Selection 智能进展评估：实现与验收记录

## 发布状态

当前是受发布门禁保护的实现，默认 `observe`。**尚未达到自动纠偏发布条件。**
工作区 `config.json` 支持：

```json
{
  "progressSupervision": {
    "mode": "observe",
    "connectionSlug": "已有的 Laufry 连接 slug"
  }
}
```

`off` 关闭评估，`observe` 只记录建议，`assist` 允许有证据的纠偏。
`assist` 还要求服务端环境变量 `CRAFT_PROGRESS_ASSIST_ENABLED=1`；验收前保持关闭。
三种模式都保留单次模型调用的资源边界。历史记录不会自动唤醒。

## 已实现

### 原始报错的新增确定根因

真实 SVG 任务发现：`submit_answer` 收到完整 `markdown` 和额外的 `intent` 展示字段，严格对象校验拒绝了整次提交，却返回“完整非空正文”错误。现已仅消费 `markdown` 并剥离多余展示字段，保留正文非空和正式交付校验。修复后，真实普通任务三次、HTML/SVG 文件任务三次均提交一份正式答案；三个 SVG 文件均实际生成。此修复不依赖监督器。

### 监督与续跑

- 独立 `ProgressSupervisor`；Laufry 无业务工具、无全局扩展、无项目指令发现的隔离调用。
- 执行期间独立检查。短模型调用不会反复推迟检查；时间只调度检查及限制资源。
- 目标、近期用户请求、工具结果、文本、Swarm 状态和 DAG revision 构成证据；证据版本绑定决定。
- 结构校验、模型身份校验、证据引用校验、过期决定丢弃。非法结果不触发纠偏。
- 推理活动仅采集字节计数，不存储新的隐藏推理副本。
- 评估 RPC 请求 ID、取消、启动/请求超时；取消传到实际 HTTP 请求。
- 正式答案、停止、认证、已有恢复、工具执行和压缩状态优先于监督建议。
- 同一任务受控续跑；专用中断确认，旧请求未确认终止时不启动新请求。
- 输出上限、连接中断、调用时长、用户交接分开处理；暂停检查点不触发答案专用重试。
- 重新生成暂停恢复旧答案；继续恢复候选 SDK 身份及独立的候选正文索引，不重复保存大段工具输出。
- Swarm 共享根评估预算；跨 worker 建议作为父会话的证据输入，父级控制权不变。
- DAG 结构建议进入已有 Coordinator gate；旧格式暂停。资源暂停复用节点会话和 attempt，不变成质量修复。
- 评估用量独立分类并计入总量。DAG 立即记账并落日志，节点完成时不重复结算评估费用。
- 工作链附近的可展开状态、证据、下一步、评估用量、任务内关闭和继续入口。

策略集中在 `packages/server-core/src/supervision/progress-supervisor.ts`，采用批准计划中的默认值。
输入按 UTF-8 字节保守预留，包含 schema 开销；无法在输入额度内保留目标时放弃评估，不裁掉目标后做决定。
取消后 provider 未回传用量时记估算，不能把估算当成精确的 token 或费用。

- 当前定向回归：1462 项通过，0 失败，覆盖 151 个测试文件。
- 全仓 `typecheck:all` 通过；项目 `lint` 通过（已有警告保留），i18n parity/sorted/coverage 通过。
- Electron 与服务端构建通过。
- 汇总结果见同目录 `progress-supervision-results.json`。

- `bun scripts/validate-progress-product.ts` 通过真实 SessionManager、Pi 子进程及 Laufry 运行三个普通任务和三个单文件 SVG 任务；保留隔离目录用于检查。
- 确定性生命周期回归覆盖身份、停止竞态、取消、资源暂停、截断恢复、重新生成事务、DAG 同会话恢复、证据过期及预算边界。
- 本地模拟 HTTP 服务确认：`cancel_llm_query` 后底层 SSE 连接断开；评估没有执行业务工具。
- 真实 Laufry 传输验证连续三次成功，回传模型、结束原因和实际 token。
- `bun scripts/validate-progress-supervision.ts [connectionSlug]` 是显式运行的真实语义验证脚本，不会替代完整产品验收。
- 2026-09-15 首次语义验证：三个场景各三次，共 9 次；8 次结果符合预期，1 次非法 JSON 被拒绝；没有据非法结果执行纠偏。真实取消调用约 104ms 返回。
- 三个语义场景分别为：证据不足的持续推理、有实质结论变化的长分析、违反已知工具合同而重复失败。
