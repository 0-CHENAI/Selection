# 任务可靠性、反馈闭环与协作：代码审查

日期：2026-09-28。审查基线为 `5dc48be8`、`be531dd4`、`a5df2e66`，补审覆盖聊天自动版本记录与 HTML 浏览器改造。审查修复随任务可靠性交付分支提交；远程验证和合并状态以关联 PR 为准。

## 确认并修复的缺陷

| 优先级 | 问题与影响 | 修复 |
| --- | --- | --- |
| P1 | 中断的成果集成恢复未调用上游输入校验，可能继续应用依赖旧输入的候选。 | 在恢复事务前执行已有 `verifyInputs`，失败时保留事务与候选。 |
| P1 | 非代码成果反馈在父会话或修订子会话撤销写权限后仍可能应用。 | 所有格式在最终应用前检查两者当前权限与取消状态；项目检查共用此检查。 |
| P1 | Shell 输出回调抛错可能成为未捕获异常，例如验证日志磁盘写满。 | 捕获回调错误，终止进程组，通过原执行 Promise 返回失败并清理资源。 |
| P1 | Linux 私有 `/tmp` 挂载会遮住先挂载的临时候选目录。 | 私有 `/tmp` 先挂载，再绑定候选与临时目录。 |
| P1 | Linux bwrap 固定切回根目录，子包检查可能在错误目录运行。 | 每次执行使用已经验证的实际工作目录。 |
| P2 | 新事务推进当前指针后，前一已应用事务无法补发交付确认。 | 从现有事务档案只读确认已应用身份；当前有未完成事务时仍拒绝，禁止重放旧写入。交付继续核对成果哈希。 |
| P2 | 文件反馈对话框与聊天修改入口重复，版本入口承担过多职责。 | 按最新产品决定移除文件反馈表单，版本窗口只读；聊天修改自动记录版本，正文批注反馈保持原入口。 |
| P1 | 工具开始事件先等待成果基线记录，再保存进行中工具；此间崩溃可能漏记未知副作用。 | 将进行中工具检查点保存移到异步成果记录之前，恢复继续保守处理未知写入。 |
| P1 | HTML 页资源规则只检查协议，外部 frame 在无 referrer 时可能复用本地文档授权。 | 基于运行时 frame 校验请求来源，限定同一文档 origin；外部 frame 无 referrer 也拒绝。 |
| P2 | HTML 窗口创建失败留下协议授权；合法 WebSocket 被拦截；显式打开隐藏 HTML 返回 404。 | 创建与导航共用失败清理，授权幂等释放；允许 ws/wss，拒绝 about:crash；仅明确打开的主文档放行隐藏文件名。 |
| P2 | 版本预览未等待实际打开结果；重复历史链接反复扫描版本存储。 | 等待打开结果并显示失败；每轮同一路径只建立一次基线，下轮仍捕获外部编辑。 |
| P1 | 主文件存在但尚未注册时，备用路径中的已注册文件可能抢占其身份，打开另一文件的版本历史。 | 存在的主路径为唯一注册依据；备用路径仅用于恢复失效主路径，多个历史身份仍拒绝猜测。 |

同时修正一项旧测试预期：受限 Shell 通过 Bash 执行命令，缺失检查命令返回 127，不能再期待 `spawn` 的 ENOENT 异常；仍验证检查失败、原文件保留及候选保留。

## 多文件版本隔离复核

- 规范文件路径关联独立成果 ID；版本 ID、序号和来源运行分别保存在各成果记录中。不同目录的同名文件、同类型文件、不同扩展名文件即使字节相同也不会合并历史。
- 内容哈希仅复用不可变存储字节。删除某一文件的旧版本后，另一文件仍引用的字节不会被回收；预览目录按完整成果 ID 与版本 ID 隔离，错传另一文件的版本 ID 会被拒绝。
- 测试交错修改四个文件，并分别核对版本序号、来源、历史预览、重新加载和单文件恢复；另外交错执行两个会话，对同名 HTML 和文本成果核对独立交付引用。
- 主路径优先规则在修复前可复现失败，修复后通过；覆盖文件移动后旧路径重新出现新文件，以及失效链接的既有恢复和歧义拒绝行为。
- 指向同一实际文件的符号链接保留同一历史；不同工作区使用独立存储，主机或工作区不匹配的记录拒绝读取。
- 测试文件：`artifact-versions.test.ts`、`conversation-artifact-versions.test.ts`、`files.artifact-notification.test.ts`、`generated-file-actions.test.ts`、`generated-file-path.test.ts`。二进制测试验证快照字节隔离，不代表新增文件格式解析或 Office 预览验收。
- 隔离及相关回归：26 个文件，216 项通过、1007 个断言；全工作区类型检查与 lint 通过，lint 仅有既有警告。
