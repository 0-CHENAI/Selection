# #327 HTML 预览缩放

全屏 HTML 使用现有 `useRichBlockInteractions` 和 `ZoomControls`。沙箱内的滚轮、捏合、鼠标拖动和键盘事件换算至外层视口后进入共享手势；链接与表单元素保留原交互。仍禁止 iframe 脚本，未改变应用窗口缩放。

切换条目、关闭后重开均复位；适应视口包含内容边距和最小高度。缩放不引入动画，因此减少动态效果设置下也不会强制移动。修复切页时旧异步读取结果覆盖当前加载状态的问题。

2026-09-10 浏览器验收使用真实 HTMLPreviewOverlay：iframe 内滚轮从 100% 到 128%，拖动改变平移；Cmd 加减与 0 正常。浏览器输入协议发送 Ctrl+滚轮，从适应比例 71% 到 108%；双击、切页和重开均回到 100%。浅色、深色均验收，链接事件未被取消，沙箱测试脚本未执行。减少动态效果时 transform transition 为 0 秒。

此记录验证浏览器的捏合事件路径；不将模拟输入当作物理触控板手感或各操作系统桌面实机验收。临时预览不提交。
