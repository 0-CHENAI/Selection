# NORM / PRO 内容衔接

2026-10-05，基于 `version-3.0` 的 `c203124cc`。

顶部模式选择的选中底板沿用现有 Motion 库做共享布局滑动。模式切换使用 Chromium 原生 View Transition 保留旧画面，在列表与当前聊天的内部内容之间做 240 毫秒柔焦交叠：旧内容从清晰淡至最多 2px 模糊，新内容从 2px 模糊逐渐清晰。两幅画面使用相同缓动 `cubic-bezier(0.16, 1, 0.3, 1)`，无中间空白；不移动或缩放内容，不做翻页。模糊只作用于短暂的截图层。

聊天窗口的背景、圆角、边框及阴影留在原来的 `PanelSlot` 外层，只有内层进入截图动画；顶部与固定侧栏不进入截图。多个聊天面板中只处理当前面板。动画不额外挂载聊天组件或输入框，不改变会话、草稿和权限的状态管理。

系统开启减少动态效果时，取消模糊，内容只淡化 150 毫秒，顶部底板直接更新位置。缺少 View Transition API 时使用相同幅度的入场柔焦动画降级，并同样遵循减少动态效果设置。重复点击及其他导航会取消尚未提交的模式更新，工作区切换与卸载会清理动画。

设计参考 [Beautiful UI Chat 的固定内容区域](https://www.beautifului.dev/#chat-composer) 与 [beUI Morphing Modal 的内容柔焦交叠和缓动](https://beui.dev/components/motion/morphing-modal)。只借鉴内容衔接，未采用示例中的高度变化、位移或缩放。实现使用原生 API 与项目已有动画库，无新增依赖。
