# Issue #350 正文流式验收

日期：2026-09-11。目标分支：test。

## 修复边界

移除完成态 Markdown 的本地揭示等待，保留真正生成期间的增量效果。当前基线中的动画常量实际上为 200 ms、上限 300 ms；用户报告的两秒不应作为当前代码的固定耗时。

`submit_answer` 参数增量通过临时预览事件展示；成功交付仍以服务端接受的正文为准。预览不进入持久化，不提供完成态操作，不改变工具执行/去重合同。拒绝、取消、错误和正式提交会清理预览。

OpenAI Completions 和 Anthropic 的拦截器会缓冲工具参数以剥离元数据。新增按异步请求隔离的预览通道，SDK 仍只收到完整且清理过的参数；Responses 等原生 SDK 增量通过 adapter 接入。无可用增量时直接显示完整正文，不模拟打字。
