# 聊天正文中的永久交接气泡

2026-10-04，基于 `version-3.0` 的 `3b8a79845`。

删除交接成功的通知气泡。在目标会话的聊天起点显示“已成功交接工作至PRO”，直接复用用户消息组件的右对齐、背景色、圆角、时间和复制操作。反向交接显示“已成功交接工作至NORM”。气泡随聊天正文滚动，没有消失计时器；长会话加载更早消息时可查看它。

显示依据是目标会话中已持久保存的 `handover-<handoverId>` 信息回执。回执只在背景应用完成后写入，重新加载会话即可恢复气泡；已有交接会话也适用。保留回执的内部信息角色，不新增用户输入，不启动模型，也不改写交接背景或原始聊天记录。缺少回执时不显示成功。紧凑聊天不再在交接气泡上叠加空会话占位文字。

## 验证

- `scripts/qa-handover-success.js` 通过：超过原有 2 秒后仍显示；离开再返回目标会话、打开已有交接会话均显示一次；源会话不增加目标气泡。
- 目标加载、等待及创建或加载失败时不误报成功；等待完成后进入目标会话才显示气泡。双向交接通过。
- 深色、浅色和 390×844 窄窗口截图确认用户气泡样式、右对齐、时间、复制按钮及正文排布，没有成功通知弹窗。
- 后端交接测试 21 项通过、161 次断言，确认回执在存储及公开会话中保留，重试不重复写入。预览使用同一真实气泡组件及固定传输模拟。
- 工作区类型检查、改动文件 ESLint、QA 脚本语法、渲染端构建和差异检查通过。`ChatDisplay` 保留 4 条原有 Hook 依赖警告，构建保留原有资源块大小提示。

截图：`handover-chat-bubble-dark.png`、`handover-chat-bubble-light.png`、`handover-chat-bubble-narrow.png`。浏览器测试结束恢复跳过确认偏好和临时视口样式。内置浏览器已更新至显示永久气泡的 PRO 预览。
