# 交接继承权限模式

2026-10-04，基于 `version-3.0` 的 `254288f4e`。

原实现把 #452 的“目标重新校验权限、不复制操作授权”处理成了新会话一律使用 `safe`，导致用户选择的询问或完全接管模式在交接后丢失。修正将当前权限模式与模型、连接一起保存为宿主创建配置，在一致快照提交时冻结，创建目标与失败重试复用它。配置独立于供模型读取的交接快照。

NORM→PRO、PRO→NORM 都继承当前权限模式。源会话后续调整不会改变已有目标，已创建目标的权限也不会被重试覆盖。旧 prepared 回执未保存权限模式时保留原来的 safe 默认；不修改已有会话数据。

单次操作审批、认证请求和凭据不复制。未知外部结果仍需复核；已完成的请求仍阻止重放。交接创建本身不启动模型或执行外部操作。
