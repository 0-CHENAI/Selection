# PRO 输入框铭牌

2026-10-05，基于 `version-3.0` 的 `6c064c3ec` 调整位置。

PRO 铭牌常驻输入框底部工具栏，位于工作目录图标右侧，使用深浅主题各自的金色文字与 1px 描边、透明背景。悬停或键盘聚焦显示项目原有 Tooltip「当前处于 PRO 模式」，支持 Escape 关闭。列表标题、聊天标题和紧凑标题菜单不再重复显示 PRO 徽标；顶部模式切换控件保留。

输入框读取实际会话或草稿的 `workMode`，加载阶段从会话元数据传递模式；NORM 不显示铭牌。桌面和紧凑输入框共用一个铭牌入口，铭牌不参与权限、模型、工作目录和发送操作。

## 本次验证

- 390×844 紧凑视口验证铭牌仍位于工作目录右侧、工具栏不溢出。截图位于 `/tmp/selection-pro-composer-badge/`。测试使用固定传输数据，没有调用模型或修改实际会话。
