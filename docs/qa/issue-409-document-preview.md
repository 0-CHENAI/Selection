# #409 文档预览验收

实现：Markdown 与 HTML 复用 PreviewOverlay；内联容器只负责限高和溢出渐隐，不再提供原地展开分支。HTML 文档阅读采用自然高度滚动，其他 HTML 预览仍保留缩放平移行为。卡片增加文件名、类型与明确边界。

审查修复：共享预览的全屏模式允许焦点进入；关闭后返回实际打开入口且不触发滚动。宽窗口 modal 分支使用 Radix Dialog，统一焦点约束、Esc 和背景滚动锁定。单份内存 HTML 不显示内部占位路径。

## 浏览器验收

使用 ego-browser 在本地 Vite 中加载真实组件，通过 PlatformProvider 注入测试文件读取结果。

- 100 段 Markdown：弹窗包含第 99 段，滚动到末尾；打开前后内联区域高度相同。
- HTML iframe 内滚轮事件：外层滚动 320px，transform 为空，不再被缩放手势吞掉。
- 100 段 HTML：iframe 高度 3866px，末段可访问，弹窗可滚动到底；内联区域高度不变。
- Esc 关闭：弹窗移除，焦点回到原入口。
- Markdown 开启后焦点位于弹窗内。
- 640×800 深色视口：弹窗宽度 640px，末段存在，焦点位于弹窗内，关闭按钮可退出。
- 单段短文档：渐隐数量为 0，没有底部完整查看按钮；Markdown / HTML 卡片高度分别为 93px / 77.625px。

以上为组件级真实浏览器验收，不等同于所有操作系统的打包应用验收。
