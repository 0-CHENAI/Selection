# #278 应用内业务确认

删除会话和退出登录继续由服务端向发起请求的客户端发送确认。preload 将请求交给 renderer 的统一 ConfirmationHost，取消或界面卸载时返回取消；未注册界面、无效响应和并发请求也不批准。WebUI 注册同一客户端能力，并使用同一弹窗实现。

项目、资产、工作区移除、模板删除以及放弃任务编辑不再调用 window.confirm；异步确认返回前不执行业务操作。批量会话删除一次展示完整数量；取消单条会话删除不再清空选中状态。

弹窗复用现有 AlertDialog 和主题按钮，危险操作使用 destructive 样式，默认焦点为取消。关闭后恢复原控件；菜单项会卸载，因此改为恢复菜单触发按钮或打开菜单前的应用控件。服务器发送业务意图，由客户端按当前语言翻译；原始英文仅作为旧客户端合同兼容字段。

## 验证

2026-09-10：完整源码测试 573 个文件、6637 项通过；随后补充真实 WebSocket 双客户端集成测试通过，确认本地/远程请求仅取得发起客户端的决定。controller、preload 桥接测试覆盖取消、重复请求、卸载、异常响应和单次批准。typecheck:all、WebUI 类型检查、仓库 lint（保留既有 warnings）、i18n parity/sorted、preload 与服务端构建通过。

真实组件浏览器检查：中文/英文文案、取消默认焦点、Escape 不执行操作、Tab 后 Enter 仅执行一次、普通按钮及菜单按钮焦点恢复均通过。420px 紧凑窗口深色主题无横向溢出；桌面宽度亦检查。预览使用计数器验证动作，不删除用户会话。Windows/Linux 原生应用实机外观未验证；共享 renderer 与真实 WebSocket 合同已测试。

## 保留原生窗口的理由

文件/文件夹选择器继续使用系统 API。开发菜单的重置说明是单按钮信息提示，不执行重置或授权危险操作；升级安装失败后运行时已清理，使用同步系统错误通知后重启，此时无法依赖 renderer 弹窗。以上均不属于业务确认—执行链。通用 __dialog:showMessageBox 业务桥接已移除。
