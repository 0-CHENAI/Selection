# PR #285：V3 YAML 导入联动验收

日期：2026-09-07。关联 #284。

## 范围与环境

- macOS ARM64，Bun 1.3.10，仓库构建的 Electron 主进程、preload 和 renderer。
- 独立 `CRAFT_CONFIG_DIR`、Electron user-data-dir 和临时工作区，不使用真实用户会话或凭据。
- 实际运行 Electron 及其 RPC/SessionManager；Playwright CDP 用于导入与截图，原生窗口操作用于复验导航、项目归属及历史任务保存。
- 测试数据通过文件或本地 API 准备；没有调用真实模型，没有启动任务运行。

## 本轮修复

- 外围入口统一为“导入编排”，同步七份语言资源。
- 无 taskSlug 的历史编辑目标明确拒绝，不再隐式创建另一个任务。
- 移除编辑器不可达的生成分支、生成结果订阅、超时、草稿回收、创建调用和单选切换栏。
- 导入错误提供本地化分类和恢复指引，保留原始字段路径/解析行列；失败保留输入。
- 增加导入中、成功但未运行、文件读取失败等反馈及可访问状态。
- 实测发现并修复 V1 表单保存误走 V3 确认的问题。既有无版本定义仍按旧合同保存为 V2 并备份。

## 真实 Electron 验收

| 场景 | 结果 |
| --- | --- |
| 从列表进入导入页 | 显示选择文件、YAML 输入、取消和导入，不展示生成/创建并运行 |
| V2 YAML 导入 | 本地化拒绝，保留输入；改为 V3 后重试成功 |
| V3 粘贴导入 | 创建任务会话并跳转；磁盘为 V3，runner 为 conduct |
| 重复 ID | 本地化提示修改 id；保留草稿，原文件未覆盖 |
| 中文文件路径 `.yaml` 导入 | 文件内容填入输入区，导入成功，可进入编辑器 |
| 非法 YAML | 保留输入，显示恢复提示及原始解析错误行列；取消能返回 |
| 项目内导入 | YAML 未声明 project 时继承项目甲，列表与会话归属一致 |
| 显式项目覆盖 | 在项目甲导入指定项目乙的 YAML，保存到项目乙并跳转对应列表 |
| 已有 V3 编辑保存 | 修改写入原文件，不新建任务、不运行 |
| 已有 V2 编辑保存 | 仍写 V2，不升级 V3 |
| 已有 V1 编辑保存 | 修复后不弹 V3 确认；写 V2，`.history` 保留原始无版本 YAML |
| 导入不自动运行 | 四个测试任务均无运行目录或模型调用 |

后台 Electron 窗口曾导致 CDP 点击稳定性等待超时；随后激活准确窗口，以原生操作复验关键场景。未将超时操作本身计为通过。
