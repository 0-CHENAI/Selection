# #334 内联 Mermaid 缩放与平移

## 修改

内联 Mermaid 复用 `useRichBlockInteractions`，在固定阅读区域内围绕指针缩放并用左键拖动画布，不改变聊天布局。复位按钮恢复原始适配尺寸；短点仍打开全屏，超过 4px 的拖动不会打开预览。每个组件保留独立状态，源代码变化和关闭全屏时恢复初始视图。

共享 hook 通过容器回调 ref 安装非 passive 滚轮监听，覆盖全屏 Portal 延迟挂载；关闭时移除监听并清理拖动。图片预览同步接入同一挂载方式。内联禁用全局键盘缩放快捷键，避免同时缩放多张图。
