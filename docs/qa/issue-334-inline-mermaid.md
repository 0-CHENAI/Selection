# #334 内联 Mermaid 缩放与平移

## 修改

内联 Mermaid 复用 `useRichBlockInteractions`，在固定阅读区域内围绕指针缩放并用左键拖动画布，不改变聊天布局。复位按钮恢复原始适配尺寸；短点仍打开全屏，超过 4px 的拖动不会打开预览。每个组件保留独立状态，源代码变化和关闭全屏时恢复初始视图。

共享 hook 通过容器回调 ref 安装非 passive 滚轮监听，覆盖全屏 Portal 延迟挂载；关闭时移除监听并清理拖动。图片预览同步接入同一挂载方式。内联禁用全局键盘缩放快捷键，避免同时缩放多张图。

## 实际 Chromium 验证（2026-09-10）

使用真实 `MarkdownMermaidBlock` 和 `MermaidPreviewOverlay`，同页两张图。

- 第一张图滚轮 -160 后缩放为 1.39474，拖动 100px/30px 后平移更新；第二张保持 `translate(0px, 0px) scale(1)`。
- 该拖动结束后 dialog 数量为 0，未误开全屏。
- 点击复位后两张图均为初始变换；随后短点正常打开全屏。
- 全屏 Portal 首次挂载后滚轮缩放至 139%，拖动可平移；Escape 正常关闭。
- 指针在图外的滚动区域时，容器 scrollTop 从 0 变为 211。
