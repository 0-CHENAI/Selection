# #322 / #325 会话删除与分支独立性

## 实现与审查

- 新分支复制源会话的附件、计划、下载及其它会话文件，并将 SDK fork 输入保存在分支自己的 `.branch-source/.pi-sessions` 中；SDK 消息内的会话文件路径同步重写，保留消息和分支锚点 ID。
- SDK 已产生分支自己的会话 ID 时，重启优先恢复该会话，保留分支后的续聊。再生成仍按原分支锚点截断，原有再生成回归继续通过。
- 删除源会话前，为仍依赖其目录的旧普通分支复制所需文件，并确认新路径落盘；不迁移 Swarm/编排 `parentSessionId` 子会话。迁移失败则不删源目录。
- 内存中不存在的会话也从已配置工作区定位目录；重复删除已不存在的会话为无操作，同名歧义会报错。
- 删除期间禁止新的发送、事件持久化和运行时创建；等待已有初始化及 SDK/MCP 运行时关闭，排空已启动的持久化写入，再删除目录。磁盘删除失败会报错，不发布成功删除事件。
- 持久化定时写入纳入与显式 flush 相同的串行队列，删除等待真实写入完成，不再靠固定延时。
