# #310 技能安装链路验收

## 实现合同

`skill_inspect` 负责只读发现，`skill_install` 在同一次工具调用内完成快照、准确内容校验、事务发布、发布内容指纹复核及加载确认。安装目标为当前工作区；不执行下载内容中的脚本，不自动安装依赖，不改变 complete/agent_settled，不注入隐藏续跑。

来源支持公开 GitHub 和本地目录；GitHub 解析 commit 后下载归档。tree/blob 链接要求显式 ref，避免含斜杠分支歧义。多候选返回路径清单。格式、静态资源及未验证的运行依赖分开报告。

同名内容相同返回 already_installed；更新需要 replace 和匹配的 expectedTargetFingerprint。暂存后再次检查目标指纹。锁、staging、备份和 journal 位于工作区的 .skill-install，不进入技能目录。准备阶段读旧版本；发布后刷新当前 Agent 目录、宿主 UI 广播及缓存。项目级遮蔽明确报告实际生效路径。

Pi 与独立 MCP 工具入口传递调用取消信号；Pi 的 abort/forceAbort/destroy 同时取消宿主在途工具。发布前取消清理 staging；开始发布后先完成验证或回滚。重启恢复只处理文件一致性，不发送模型消息。Windows 不将 POSIX 可执行位用于指纹比较，但源归档的执行位在支持平台保留。

## 审查修复

- 不经 slug 再解析校验对象，避免校验到同名项目级旧技能。
- 校验发布后的指纹，发布前重新检查目标变化，避免长时间暂存后覆盖已变化目标。
- 新安装 rename 未成功时，回滚不删除后来出现的目录。
- 准备阶段保留旧读取视图；恢复中的进程再次退出后，带恢复进程 ID 的事务目录仍可发现，安装器不会与恢复同时写入。
- 格式错误、明确资源缺失、目录外引用、符号链接、特殊文件、便携路径冲突和体积超限均阻止发布。
- 除下载量、文件数量和内容大小外，也限制总解压流量（含元数据/填充）；校验路径冲突采用集合查找，避免平方级扫描。
- 原始流只用于快照，不执行远端代码；脚本运行能力始终标记 not_verified。
- 回滚后的通知失败不再保留一个已经没有必要的文件锁。
