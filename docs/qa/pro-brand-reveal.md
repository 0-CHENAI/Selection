# PRO 铭牌三连击与品牌展示

日期：2026-10-05。基线：`6a8fb7ff3`，本地 `version-3.0`。

实际输入区的 `SessionModeBadge` 改为按钮，禁用文字选择和双击默认行为。鼠标、触控在相邻点击间隔不超过 500ms 时，第三次点击打开品牌展示；间隔较长重新计数。键盘/辅助技术保持按钮的标准单次激活方式。模式改变使铭牌卸载时，不保留打开状态。

展示层使用现有 Radix Dialog 处理焦点和背景交互隔离，覆盖整个应用文档，不只覆盖聊天面板。复用新建会话的天鹅图标和 Selection 字样资源；主题反色放在图像层，柔焦动画放在外层，避免动画覆盖深色图像的反色。

## 呈现与时序

天鹅图标、Selection 和右侧 PRO 组成一个居中的横排。Selection 与 PRO 共用一个垂直居中的文字容器，PRO 最大显示字号约 42px，间距随窗口在 16–24px 之间变化。PRO 的 SVG 裁掉多余空白并随窗口缩放；动画开始前预留其位置，显示过程中不会推动品牌组合。

PRO 在垂直中心基础上向下微调 3px。本次动效调整基于 `5000b87fa`，保留字号、位置和品牌显现后的 0.5 秒停顿。

参考 [GSAP Timeline 的分段与相对时序](https://gsap.com/docs/v3/GSAP/Timeline/)，用现有 CSS 动画实现有限序列，没有新增依赖。

| 相对打开时间 | 呈现 |
| --- | --- |
| 0–0.64 秒 | 全窗口遮罩与 12px 柔焦逐渐进入；浅色遮罩黑色透明度 10%，深色 24%。 |
| 0.10–1.00 秒 | 天鹅标志由轻微失焦变清晰；Selection 字样在 0.20 秒开始，于 1.00 秒显现完成。 |
| 1.50–2.30 秒 | 间隔 0.5 秒后，PRO 整体从轻微失焦变清晰，字距从 0.28em 收束至 0.22em，使用自然减速曲线落定。浅色使用铜金，深色使用香槟金，复用 `--pro-accent`。 |

PRO 保持单层、实心金色字面，移除描边绘制、叠层和扫光。聚焦与字距收束作为同一个排字动作，没有弹跳、循环、亮度闪动或位置移动。

字样保持显示，用户可通过空白处、关闭图标或 Esc 退出；退出动画 240ms。关闭后焦点返回铭牌，恢复背景的指针交互。打开展示时直接卸载提示内容，避免提示框的退出阶段抢先处理 Escape。确认在品牌透明度仍为零时，也能立即退出。

系统减少动态效果时，不使用空间移动、柔焦和字距收束，改为 150ms 淡入：品牌完成后停顿 0.5 秒再显示 PRO。触控按钮使用 `touch-action: manipulation`，不将连续点击解释为双击缩放。仅键盘操作显示关闭图标的可见焦点框。

## 验证

- 交互逻辑在现有 Playground 的真实 `FreeFormInput` 组件中验证；传输使用固定预览数据，不启动模型。本次横向布局在实际 Electron 窗口中确认三连击打开、整体居中、Esc 退出及焦点恢复，不更改真实会话。
- 原生鼠标双击后没有文字选择，也没有弹层；原生鼠标三连击和触控三连击均只在第三次打开。
- 验证慢速点击不触发、键盘 Enter 打开、Esc 与空白点击关闭、提前退出、反复打开、焦点恢复和指针锁清理。
- 浅色主题确认品牌图像为黑色；深色主题确认遮罩透明度与香槟金令牌。本次横向布局截图显示完整的品牌组合；未重跑窄窗口视觉检查。
- 减少动态效果沿用已验证的 650ms 延迟、150ms 淡入路径；本次代码检查确认该路径不使用聚焦和字距收束。
- 全仓类型检查和最终 Electron 类型检查通过；修改的 TSX 文件 ESLint 通过；Impeccable 机械检测无发现；renderer 生产构建通过。
- 原有模式导航与新建品牌测试共 4 项通过，`git diff --check` 通过。

首版检查发现深色品牌图像的反色未生效，已改为显式的主题 CSS，并保留外层柔焦动画。该修复通过类型、lint 和生产构建检查；当时视觉复核因 Mac 锁定且原浏览器预览已关闭受阻，未取得修复后的深色截图。

## 铭牌焦点样式

展示层关闭后，焦点返回铭牌会触发可见焦点样式。原来的 2px 外圈与 2px 间隙产生了第二层外框，现改为 1px 内部描边，保持铭牌单层轮廓。

实际 Electron 窗口确认三连击打开、Esc 关闭后焦点返回且没有外圈；随后 Enter 仍能打开，Esc 再次关闭并恢复焦点。此次样式调整通过 Electron 类型检查、文件 ESLint、Impeccable 机械检测和 renderer 生产构建。
