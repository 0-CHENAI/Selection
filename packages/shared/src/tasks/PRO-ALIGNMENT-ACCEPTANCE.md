## 已发现并修复的阻断项

- 普通包漏打 Pi 子进程与原生运行资源。
- 双层禁止 Agent 创建规范计划，以及创建/启动重试产生重复归属。
- 协调者在待调度检查点被强迫提前交付最终答复；恢复回合无法读取自身执行状态。
- 独立审查错误指定未执行的返修目标，导致历史操作重放。
- 上游 5xx 含代理认证信息时被误识别为用户凭据失效。
- 子节点身份在提供方配置投影中丢失；上下文复用缺少已确认读写和外部变化校验。
